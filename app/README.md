# 메디온 Flutter 앱

메디온 웹 서비스의 화면 구성을 안드로이드 앱 형태로 옮긴 Flutter UI 프로젝트입니다.

## 화면

- 홈
- 진료과 찾기
- 건강 정보
- 공지사항
- 이용 안내
- 로그인
- 회원가입
- 마이페이지
- 의료기관 상세

## 구현된 화면 동작

- 하단 탭 및 화면 간 이동
- 데이터베이스 기반 주변 의료기관·진료과 검색과 카테고리 필터
- 내 즐겨찾기, 진료 중, 진료과목, 반경, 진료 시간 필터
- 페이지당 의료기관 30곳과 이전·다음 페이지 이동
- 응급실 실시간 가용 병상 조회
- OpenStreetMap 지도와 의료기관 마커·상세 선택
- GPS 현재 위치 및 주소 검색을 이용한 검색 기준 위치 변경
- 공지 분류 선택과 상세 내용 펼치기
- 로그인·회원가입 입력 검증과 비밀번호 표시 전환
- 백엔드 API 기반 회원가입·로그인·로그아웃
- 실제 주소 검색 API를 이용한 가입 주소 선택과 마이페이지 주소 변경
- 마이페이지 설정 선택과 즐겨찾기 관리

회원 정보와 주소는 `backend`의 인증 API를 통해 데이터베이스에 저장됩니다.
Android 에뮬레이터에서는 기본적으로 `http://10.0.2.2:8080`에 연결합니다.
실기기나 다른 서버를 사용할 때는 아래처럼 백엔드 주소를 지정해 주세요.

```text
--dart-define=API_BASE_URL=http://192.168.0.10:8080
```

주소 검색을 사용하려면
`backend/src/main/resources/application-secret.properties`에
`app.naver-maps.api-key-id`와 `app.naver-maps.api-key`를 설정해야 합니다.
의료기관 검색 결과와 즐겨찾기는 백엔드 API를 통해 데이터베이스에서
조회하고 저장합니다.
